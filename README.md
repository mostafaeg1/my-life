# Project Time Tracker

A simple web app to track how much time you spend on different projects — homework, reading, side projects, or anything else you want to measure.

## Features

- Add projects as simple named sections (no GitHub or external links required)
- Select a project and start a focus session
- Live timer while you focus
- Session time is added to that project's total when you stop
- Data is saved in your browser (localStorage)

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```
